# Bank Statement Renamer

银行水单 PDF 文件批量重命名工具，支持中信银行、华夏银行、广发银行等常见银行水单的标准化命名。

## 命名规范

```
[交易日期] BANKBLL [水单类型] [交易对方名称] [款项用途] [金额].pdf
```

### 示例

```
20260415 BANKBLL 付款水单 国家金库北京市海淀区支库 增值税及其附加税费 151.37.pdf
20260424 BANKBLL 收款水单 国家金库北京市海淀区支库 税款退库款 29,427.66.pdf
20260506 BANKBLL 付款水单 北京艾迪尔建筑装饰工程股份有限公司 合同款 180,000.00.pdf
```

### 水单类型

- `收款水单` — 对方付款给我方
- `付款水单` — 我方付款给对方

### 款项用途（付款）

| 用途 | 适用场景 |
|------|---------|
| 银行手续费 | 跨行转账、账户服务费 |
| 工资款 | 代发工资 |
| 社保款 | 社保缴纳 |
| 个税费 | 个人所得税扣缴 |
| 公积金款 | 公积金缴纳 |
| 增值税及其附加税费 | 增值税、城建税、教育附加等 |
| 企业所得税费 | 企业所得税 |
| 税费 | 无法区分税种的税款支付 |
| 报销款 | 员工费用报销 |
| 商务卡还款 | 员工信用卡还款 |
| 合同款 | 合同相关付款（定金/押金/预付款） |
| 租赁费 | 房租租赁费 |
| 物业费 | 物业管理费 |
| 公司内部转账款 | 同公司不同账户间转账 |
| 关联方往来款 | 与关联公司间的往来款 |

### 款项用途（收款）

| 用途 | 适用场景 |
|------|---------|
| 关联方往来款 | 关联公司转入 |
| 货款 | 销售商品收款 |
| 服务费 | 提供服务收款 |
| 利息收入 | 存款利息 |
| 员工贷款还款 | 员工归还借款 |
| 税款退库款 | 税款电子退库 |

## 使用方法

### 方式一：命令行

```bash
# 预览模式（dry-run）
python scripts/rename_statement.py <目录路径> --dry-run

# 执行重命名
python scripts/rename_statement.py <目录路径>

# 指定公司信息
python scripts/rename_statement.py <目录路径> \
  --account 8110701012802583187 \
  --company-name "北京磐旭科技有限公司"
```

### 方式二：对话式

将水单 PDF 文件放入一个文件夹，直接告诉我"帮我重命名这个文件夹里的水单"，我会自动读取 PDF 内容并完成重命名。

## 特殊规则

- **同名账户互转**：以基本户为判断基准，转入基本户 = 收款水单，转出基本户 = 付款水单
- **电子退库（税款退回）**：收款水单，款项用途填"税款退库款"
- **员工商务卡还款**：交易对方填员工姓名，款项用途填"商务卡还款"
- **同日多笔付给同一方**：按各笔摘要分别填写用途，无需额外区分
- **中信银行收费回单**：交易对方填本公司名，款项用途填"银行手续费"
